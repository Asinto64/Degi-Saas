# DEGI | Design & Creative Collaboration Workspace

DEGI is a sleek, modern landing page for a collaborative workspace designed for creative teams—combining live canvas co-editing, linked documentation, and threaded feedback into a single, cohesive platform.

## Features

- **Live Collaboration Mockup**: An interactive dashboard preview demonstrating live session editing and comment resolution tracking.
- **Dynamic Feature Bento Grid**: A layout highlighting platform capabilities (live canvas, creative docs, approval flows, brand systems) in a neat, responsive grid.
- **Interactive Pricing Plan Toggle**: A pricing grid supporting toggle modes for monthly and discounted annual subscriptions.
- **Smooth Navigation & Scroll Animations**: Interactive navigation controls, scrolling cues, and entry animations for page sections.
- **Bespoke Glassmorphism Theme**: Vibrant backdrop glow effects, dark backgrounds, and gradient styling following high-end SaaS designs.

## Stack & Libraries Used

- **HTML5 & CSS3**: Responsive grid layouts, CSS custom properties (variables), glassmorphic card overlays, and dynamic gradients.
- **JavaScript**: Local states for metric tracking, dynamic billing toggle calculations, form submissions, and menu controls.

## Running Locally

To host the files locally:

1. Navigate to the project directory:
   ```bash
   cd "sample 2"
   ```
2. Serve using any static server. For example, using Node's `http-server`:
   ```bash
   npx http-server -p 8100 -c-1
   ```
3. Open `http://localhost:8100` in your browser.
